# 배액 측정기 펌웨어 0.9 (DrainMeter)

고설 딸기 베드 한 라인(약 80m)의 배액을 통째로 받아 **무게로 재는** 장치입니다.
한 동 6라인 중 2라인(가운데 1, 측창 쪽 1)에 달고, ESP32 보드 하나로 두 통을 함께 잽니다.
D셀 3개로 6개월 이상 쓰는 것이 목표입니다.

0.9 버전은 와이파이 없이 전자잉크 화면에만 표시합니다. EC·pH와 와이파이는 1.0에서 추가합니다.

## 왜 이 방식인가

| 기존 방식 | 문제 | 이 장치 |
|---|---|---|
| 전도식(시소) 바가지 | 바가지가 작으면 많이 흐를 때 덜 세고, 크면 정밀도가 떨어짐 | 무게로 재서 유량과 상관없이 10~50mL 단위 |
| 배지 일부만 계량 | 배지 몇 개만 재서 라인 전체를 대표하지 못함 | 라인 전체 배액을 통으로 받음 |
| 전동·솔레노이드 밸브로 비우기 | 밸브에 전원이 필요함 | 부력과 자석 잡이로 전기 없이 비움 |
| 홀센서 유량계 | 끝무렵 졸졸 흐르는 배액을 못 잼 | 무게라 흐름 세기와 상관없음 |

## 기계 구조

배수구(바닥 배관에서 T로 10cm 올라온 관) 위에 얹는 일직선 구조입니다. 베드는 고치지 않습니다.

```
배액관 끝
  ↓  (뚜껑 위로 떨어짐)
[통 20L]  센서 컵, 부표(힌지 팔), 양변기 배수밸브 + 플래퍼
  ↓  20mm 리듀서 관 (T 세운 관 안으로 2~3cm, 닿지 않게)
[T 세운 관 10cm] → 바닥 배관 50mm
```

- **통**: 20L, 바닥이 평평한 사각 통. 1회 급액의 배액(11~16L)이 다 들어가서 배액이 끝난 뒤 한 번에 비워진다.
- **배수밸브**: 양변기 배수밸브(2인치, 플래퍼 포함)를 통 바닥 가운데에 단다. 출구에 20mm 리듀서를 달아 천천히 빠지게 한다 (평균 약 0.3L/초, 15L에 약 50초). 바닥 배관이 거의 수평이고 T 높이가 10cm라 2인치 그대로 쏟으면 넘칠 수 있다.
- **넘침관**: 밸브 가운데 넘침관은 밸브 출구로 이어진다. 플래퍼가 안 열려도 넘친 물이 배수구로 빠져서 바닥으로 넘치지 않는다.
- **부표와 자석 잡이**: 넘침관에 클램프로 힌지를 달고, 팔(약 15cm) 끝에 부표를 단다. 부표 안쪽 바닥에 네오디뮴 자석을 넣고(물에 닿지 않게), 통 바닥 바깥에 쇠판을 둔다. 부력이 자석 힘을 넘는 순간 부표가 떨어지면서 팔 중간에 묶은 줄이 플래퍼를 당겨 한 번에 연다. 반쯤 열려 조금씩 새는 상태가 생기지 않는다.
  - 쇠판은 자석에 붙는 430 스테인리스나 도장한 철판. 304 스테인리스는 자석에 거의 안 붙는다.
  - 부표가 붙어 있을 때 플래퍼 줄은 1cm 정도 느슨하게.
  - 팔 위쪽에 멈춤대를 둔다.
  - 부표가 완전히 잠겼을 때의 부력이 자석 힘보다 확실히 커야 한다 (예: 1L 부표 ≈ 1kg 부력이면 자석 힘 0.4~0.6kg).
- **센서 컵 (1.0)**: 배액이 떨어지는 자리 아래 통 안쪽 벽에 200~300mL 컵. 배액이 컵을 채우고 넘쳐 통으로 간다. 통이 비어도 컵은 차 있어 pH 센서가 마르지 않고, 무게도 늘 같다. 컵 윗면은 넘침관 끝보다 높게. 센서는 뚜껑의 케이블 글랜드로 꽂는다.
- **로드셀 판**: 50kg(4개 합) 세트. 위판과 아래판 가운데에 40~50mm 구멍을 뚫어 밸브 아래 관이 어디에도 닿지 않게 한다. 통은 판 가운데에 올린다.
- **높이**: 바닥에서 뚜껑까지 약 70cm. 배액관 끝이 그보다 높아야 한다.
- **거름망**: 배액이 들어오는 쪽에 단다. 플래퍼 고무에 찌꺼기가 끼면 샌다.

## 부품

라인마다 1세트 (2세트)

- 20L 사각 통, 양변기 배수밸브 세트(2인치), 20mm 리듀서와 짧은 관
- 부표, 힌지 팔(옛날식 볼탭 부품을 써도 됨), 네오디뮴 자석, 430 스테인리스 쇠판
- 로드셀 50kg(4개 합) 세트 + HX711, 받침, 위판과 아래판
- 리드 스위치 1개 (부표 잡이 감지)
- 거름망, 받침대

공용 1세트

- Seeed XIAO ESP32C6
- 전자잉크 2.9인치 흑백 296x128 (SPI 모듈형)
- DS3231 RTC 모듈 + CR2032 (또는 LIR2032)
- 버튼 1개, 1MΩ 저항 1개, 100kΩ 저항 1개, 470~1000µF 콘덴서
- D셀 3개 홀더(스위치 달린 것), 방수 케이스, 케이블 글랜드
- 1.0에서 추가: EC·pH 모듈(절연형, I2C), 수온 센서, PCF8574, FPC 안테나

## 핀 배치 (XIAO ESP32C6)

| 핀 | 연결 |
|---|---|
| MTCK (GPIO6, 뒷면 패드, 깨우기) | 부표 잡이 리드 스위치 2개 (직렬) |
| MTDO (GPIO7, 뒷면 패드, 깨우기) | 버튼 |
| D0 | HX711 #1 DOUT (1라인) |
| D1 | HX711 #2 DOUT (2라인) |
| D2 | HX711 SCK (2개 공용) |
| D3 | 전자잉크 CS |
| D4, D5 | I2C SDA, SCL: DS3231 (1.0에서 PCF8574, EC·pH 모듈) |
| D6 | 전자잉크 DC |
| D7 | 전자잉크 RST |
| D8 | 전자잉크 SCK |
| D9 | 전자잉크 BUSY |
| D10 | 전자잉크 DIN |

- 잠에서 깨울 수 있는 핀은 LP GPIO(0~7)뿐이다. XIAO에서는 D0~D2와 뒷면 패드 4개.
- 뒷면의 GPIO4(MTMS), GPIO5(MTDI)는 스트래핑 핀이라 쓰지 않는다.
- 뒷면 패드는 작아서 가는 선을 납땜하고 글루건으로 고정한다.

## 배선 메모

- **전원**: D셀 3개 직렬(약 4.5V)을 XIAO의 **5V 핀**에 넣는다. 3.3V 핀에 직접 넣으면 안 된다. 5V 핀 옆에 470~1000µF 콘덴서.
- **3.3V**: HX711, DS3231, 전자잉크는 모두 XIAO의 3V3 핀에서 받는다. 5V에 물리면 ESP32 핀에 5V가 걸린다.
- **HX711**: 두 모듈의 SCK를 D2 하나에 같이 잇는다. 모듈의 RATE 핀이 GND(10회/초)인지 확인한다.
- **로드셀 4개**: 각 센서의 가운데 선(나머지 두 선과 각각 약 1kΩ)을 HX711 E+, E−, A+, A−로, 나머지 두 색은 이웃끼리 묶는다. 대각선 센서끼리 한 쌍(E+/E−, A+/A−). 네 센서 모두 같은 면이 위로.
- **리드 스위치**: 부표 자석이 붙어 있으면 닫히는 위치(쇠판 옆, 통 바닥 바깥)에 단다. 두 라인 스위치를 **직렬**로 GPIO6과 GND 사이에 잇고, GPIO6에서 3V3로 **1MΩ 풀업**. 둘 다 붙어 있으면 LOW, 하나라도 떨어지면 HIGH. 어느 쪽인지는 깨어나서 무게로 안다. 풀업이 크면 닫혀 있는 동안 흐르는 전류가 약 3µA.
- **버튼**: GPIO7과 GND 사이, GPIO7에서 3V3로 100kΩ 풀업. 누르면 LOW.
- **DS3231 모듈(ZS-042)**: 항상 켜진 전원 LED를 떼고, CR2032를 쓰면 충전 회로 저항(또는 다이오드)을 뗀다.
- **네오디뮴 자석**: 물에 닿는 자석은 에폭시나 열수축 튜브로 빈틈없이 감싼다.

## 전력 (D셀 3개, 0.9 기준)

하루 약 2~4mAh (10분마다 무게 재기, 물 빠질 때 깨어나기, 전자잉크 갱신, 잠자기).
D셀 3개는 1만mAh 이상이라 6개월에 충분하다. 1.0에서 EC·pH와 와이파이를 더해도 하루 약 7mAh.
저전력 동작은 보드가 잠잘 때 수십 µA 이하일 때 얘기다. 개발 중 USB를 꽂은 상태는 해당하지 않는다.

## 빌드 (VS Code + PlatformIO)

1. VS Code에서 이 폴더(`DrainMeter`)를 연다.
2. 처음 빌드는 pioarduino 플랫폼과 도구를 내려받느라 몇 분 걸린다.
   오류가 계속 나면 사용자 폴더의 `.platformio` 폴더를 지우고 VS Code를 다시 시작한다.
3. 업로드가 안 되면 (보드가 잠들어 USB가 끊긴 경우) BOOT 버튼을 누른 채 RESET을 눌렀다 뗀다.

| 환경 | 하는 일 |

```
pio device monitor
```

## 부품 시험 순서

부품을 하나씩 연결해 확인한 뒤 본 펌웨어를 채운다.

1. **RTC** (`test_rtc`): I2C 주소 0x68이 보이는지 확인하고, `set 2026-11-13 21:30:00`처럼 시각을 맞춘다. 전원을 껐다 켜도 시각이 이어지는지 본다.
2. **로드셀** (`test_scale`)
   - 위판의 네 귀퉁이를 하나씩 눌러, 어디를 눌러도 값이 같은 방향으로 바뀌는지 본다. 한 곳만 반대면 그 센서 배선이 틀렸다.
   - 아무것도 안 올리고 `t`(영점), 무게를 아는 물건(예: 물 1L = 1000g)을 올리고 `c1 1000`(2라인은 `c2 1000`).
   - 나온 값을 `config.h`의 `SCALE1_COUNTS_PER_G`, `SCALE2_COUNTS_PER_G`에 적는다.
   - 가만히 둔 상태의 흔들림이 몇 g인지 적어 둔다.
   - `z`로 쉬기/깨기를 몇 번 해 보고, 깨어난 뒤 값이 바로 돌아오는지 본다.
3. **전자잉크** (`test_epd`): 한글이 제대로 나오는지, 전체/부분 갱신 시간이 얼마인지 본다. 깨지거나 안 나오면 아래 표로 `EPD_DRIVER`를 바꾼다.

한글 글꼴(`u8g2_font_unifont_t_korean2`)은 자주 쓰는 글자만 들어 있다. 화면에 쓸 글자가 빠지면 네모로 나온다.

### 전자잉크 패널 종류 (`config.h`의 `EPD_DRIVER`)

| 모듈 | EPD_DRIVER |
|---|---|
| Waveshare 2.9" 흑백 V2 (GDEM029T94, SSD1680) | `GxEPD2_290_T94_V2` (기본값) |
| Good Display GDEM029T94 | `GxEPD2_290_T94` |
| Good Display GDEY029T94 | `GxEPD2_290_GDEY029T94` |
| DKE DEPG0290BS | `GxEPD2_290_BS` |
| 구형 Waveshare 2.9" V1 (IL3820) | `GxEPD2_290` |

## 실물로 맞춰야 하는 값

| 값 | 어디 | 어떻게 |
|---|---|---|
| 저울 1g당 읽음값 | `config.h` `SCALE1/2_COUNTS_PER_G` | `test_scale` 보정 |
| 전자잉크 패널 종류 | `config.h` `EPD_DRIVER` | `test_epd` |
| 비우는 데 걸리는 시간 | 1회 측정해 기록 | 통을 가득 채워 비우며 시간 재기 |
| 부표가 떨어지는 무게 | 1회 측정해 기록 | 물을 천천히 부으며 떨어질 때 무게 |
| T 세운 관에 물이 차오르는 높이 | 기록 | 비울 때 관찰. 위로 5cm 이상 남아야 안심 |

## 0.9에서 할 일

1. 잠자기 구조: 10분마다 RTC 시각 기준으로 깨어 두 저울을 재고 다시 잔다. 리드 스위치(GPIO6)와 버튼(GPIO7)으로도 깬다.
2. 배액량 계산: 무게가 늘어난 만큼 더한다. 비우기 전 무게와 비운 뒤 무게를 빼서 버린 양으로 더하고, 비우는 동안 들어온 양은 비우기 직전 무게가 늘던 속도로 보정한다. 비운 뒤 0점을 다시 잡는다.
3. 급액 회차 나누기: 무게가 늘다 멈추면 한 회차가 끝난 것으로 본다.
4. 기록: 날짜별, 회차별 배액량을 보드 메모리에 저장한다 (1.0에서 와이파이로 보낸다).
5. 화면: 오늘 배액, 최근 1회 배액, 전지 전압, 시각. 버튼으로 오늘/어제/최근 7일 넘기기. DS3231 칩 온도가 0°C 아래면 갱신하지 않는다.
6. 고장 알림: 무게가 넘침 높이에서 더 안 늘면 "안 열림", 배액이 있어야 할 때 한쪽만 0이면 "플래퍼 확인".
