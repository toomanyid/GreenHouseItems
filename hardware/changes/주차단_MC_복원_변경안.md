# 주 차단 MC 복원 변경안 (2026-10-24, 반영함)

2026-10-18에 뺀 주 릴레이 자리를 MC(전자접촉기)로 되살린다. 아래는 **아직 반영하지 않은 변경안**이다. 확인을 받으면 Google 문서 세 개와 회로도에 반영한다.

가정(코일 구동 방식은 사용자 결정 대기): MC는 DC 24V 코일이고, 예전 주 릴레이 구동 회로(FET 2개 직렬, IO17·IO21)로 코일을 켠다. MC는 24V 직류 쪽, 주 퓨즈와 BTS7960 사이에 둔다.

## 1. 회로 구조

- 전원 경로: 24V 입력 → 주 퓨즈 → 입력 큰 콘덴서와 TVS → **MC 주접점** → BTS7960 2개 → 자동 소켓 → 모터 퓨즈 → 모터.
- 50W: MC 1대, 주접점 1극만 쓴다.
- 300W: 3극 MC 1대. SMPS가 채널마다 따로이므로 채널마다 한 극씩 쓰고 두 채널을 섞지 않는다. 예전의 릴레이 2개를 MC 하나로 바꾸는 셈이다.
- 수동 소켓용 24V는 지금처럼 주 퓨즈 뒤, **MC 앞**에서 딴다. MC가 떨어져 있어도 수동 조작은 된다.
- 코일: 24V_F → J2(MC 코일) → FET A(IO17) → FET B(IO21) → GND. IRLZ44N 2개, 게이트 직렬 100Ω, 풀다운 10k, FET 사이 100k, 코일 양단 1N4007. 두 FET가 모두 켜져야 MC가 붙으므로 FET 하나가 합선돼도 MC가 저절로 붙지 않는다.
- MC 뒤 전압 감지: J3에 RLY_OUT 핀을 되살리고 100k/10k 분압, 100nF으로 IO6에서 읽는다. 300W는 두 극 뒤 전압을 다이오드 2개(1N4148)로 묶어 같은 분압에 넣는다. 어느 극이든 접점이 붙으면 잡힌다.
- 방전 저항: MC 뒤(드라이버 쪽)에 4.7kΩ 1W를 단다. 떼고 나서 전압이 빨리 빠져야 접점 붙음 검사가 맞는다.
- 콘덴서 위치: 큰 입력 콘덴서(2200µF, 4700µF)는 MC 앞에 둔다. MC 뒤 드라이버 가까이는 100µF 이하만 둔다. MC가 붙을 때 큰 콘덴서로 돌입 전류가 몰려 접점이 붙는 것을 막는다.
- 24V_F 다이오드 D1, D2: MC 코일 전류(DC 24V 코일 약 0.2~0.4A)가 더해지므로 1N5819(1A) → 3A급(빵판 1N5822, PCB SS34)으로 바꾼다.

## 2. 문서별 변경

### 설계 정리
- 개요 표에 "주 차단" 줄 추가: 50W "MC 1대 (DC24V 코일, 1극 사용)", 300W "MC 1대 (3극, 채널마다 1극)".
- 전원 절의 내부 전원 경로 순서에 MC 단계를 넣고, "주 릴레이가 없으므로 위치 제약은 없다"를 "큰 입력 콘덴서는 MC 앞, MC 뒤에는 100µF 이하"로 바꾼다.
- 300W 드라이버 절의 "모듈 가까이에 입력 콘덴서를 둔다"를 "모듈 가까이에는 100µF 이하만, 큰 콘덴서는 MC 앞"으로 바꾼다.
- 안전 회로 절을 다시 쓴다: 평소에는 MC가 떨어져 있고, 구동할 때만 붙인다. 붙이는 순서(MC → 0.1초 → EN), 떼는 순서(EN 끄기 → 0.1초 → MC), 전원 켤 때 자가 점검, 접점 붙음 감지. 고장별 동작에서 "대각선 소자 두 개가 붙으면 퓨즈가 안 끊긴다" 경우는 MC를 떼서 멈춘다로 바뀐다. 퓨즈는 관통 단락 보호로 그대로 둔다.
- 베이스 보드 연결 표에 "MC 코일 | 나사 단자대 2P | 24V_F, COIL−" 추가, 감지 입력 2P → 3P(비상정지 감지, RLY_OUT, GND).
- 부품 수량: MC 1대 추가, 낱개 반도체 표에 IRLZ44N 2개, 1N4007 1개(코일), 1N4148 2개(300W 감지 묶음) 추가, 1N5819 → 1N5822/SS34, 방전 저항 4.7kΩ 1W 추가.
- 입출력 보호회로 점검 절: 24V_F 다이오드 항목에 MC 코일 전류를 넣고, "제작 전 확인"에 MC 직류 차단 정격 확인을 넣는다(평소에는 EN을 먼저 끄므로 무부하 개폐지만, 고장 때를 위해 DC 24V 정격을 확인).

### 핀 배정
- 6: 여유 → **MC 뒤 전압 감지**, 아날로그 입력, 분압 100k/10k, 핀에 100nF.
- 17: 여유 → **MC 코일 FET A** (코일 쪽), 출력, 직렬 100Ω, 풀다운 10k.
- 21: 여유 → **MC 코일 FET B** (GND 쪽), 출력, 직렬 100Ω, 풀다운 10k.
- 남는 핀: 18, 19, 20, 40번.

### 소프트웨어 스펙
- 6절 "드라이버 이상 감시"를 "주 차단 MC"로 바꾼다. 자가 점검(FET를 하나씩 켜서 MC 뒤 전압이 안 생기는지), 붙이고 떼는 순서, 뗀 뒤 3초 안에 전압이 안 빠지면 ERR RELAY(두 창 모두 고장, 전원을 다시 켤 때까지 유지).
- MC 유지 시간(2026-10-24 추가): 두 창이 모두 멈춘 뒤에도 MC를 **10초** 더 붙여 둔다. 그 안에 다음 이동이 오면 MC를 다시 붙이지 않고 바로 구동한다. 10초가 지나면 떼고 접점 붙음 검사를 한다. 단 비상정지, 고장(FAULT), MC 고장 때는 유지 시간 없이 바로 뗀다. 유지 중에도 EN은 꺼져 있으므로 EN 꺼짐 중 전류 감시는 그대로 돈다.
- 8절 config.h 상수 표에 "MC 유지 시간 | 10초" 추가.
- EN 꺼짐 중 전류 감시(ERR DRIVER)는 그대로 둔다. MC가 붙어 있는 동안의 드라이버 고장을 잡는다.
- 7절 고장 문구에 ERR RELAY를 되살린다.

## 3. 회로도
- 빵판 회로도와 베이스 보드(base.py D·A·J 패널)를 2026-10-18 제거 목록의 반대로 되돌리고, 위의 MC 표기, 300W 다이오드 묶음, 방전 저항, D1·D2 변경을 넣는다.

## 4. 펌웨어
- WinCtrl에는 주 릴레이 코드(dev_Relay, RelayControl, ERR RELAY)가 아직 남아 있어 동작은 그대로 쓴다. 주석의 "릴레이"를 "MC"로 바꾸고, RelayControl에 MC 유지 시간 10초(config.h 상수)를 넣는다(비상정지·고장 때는 바로 뗌). MC 붙는 시간이 0.1초 안인지 실물로 확인해 RELAY_SETTLE_MS를 맞춘다.
