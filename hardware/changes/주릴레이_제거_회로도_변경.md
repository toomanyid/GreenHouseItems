# 주 릴레이 제거에 따른 회로도 변경 (2026-10-18)

사용자 결정: 주 릴레이를 없애고, 드라이버 고장(합선) 때는 주 퓨즈가 끊어지게 한다.
Google 문서(설계 정리, 핀 배정, 소프트웨어 스펙)는 이미 고쳤다. 회로도 두 장에 아래를 반영한다.

## 빵판 회로도 (breadboard/빵판_회로도.svg)
- 지운다: J2(주 릴레이 코일 단자), D2 1N4007, Q1·Q2 IRLZ44N, 게이트 직렬 100Ω 2개, 게이트 풀다운 10k 2개, FET 사이 100k.
- 지운다: J3(주 릴레이 뒤 24V 단자)와 그 분압 100k/10k, 100nF. IO6은 여유로 표시.
- IO17, IO21은 여유로 표시.
- 아래 메모 줄에서 "주 릴레이 접점 → BTS7960 B+"를 "주 퓨즈 → 입력 콘덴서 + 1.5KE30A → BTS7960 B+"로, 주 릴레이 설명 줄은 삭제.

## 베이스 보드 회로도 (baseboard/src/base.py)
- D 패널: J2, D3, Q1, Q2, 100Ω·10k·100k, J3의 RLY_OUT 줄과 분압을 지운다. J3은 2P(ESTOP, GND)가 된다. 패널 제목은 "D. 비상정지 감지".
- A 패널: IO6, IO17, IO21을 여유(NC)로.
- J 메모: 모터 전류 경로에서 "주 릴레이 접점(뒤 24V를 J3 RLY_OUT으로) →"를 지운다.

## 그대로 두는 것
- 비상정지 감지(IO1, JP1)와 300W 비상정지 릴레이(보드 밖)는 그대로다.
