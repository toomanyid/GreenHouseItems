# WinCtrl: 측창 모터 제어기 펌웨어

ESP32-S3(N16R8) 한 대로 비닐하우스 측창 모터 2대를 초 단위로 여닫는 제어기의 펌웨어다.
설계와 결정은 claude.ai 프로젝트 "비닐하우스 개폐기 제어기"에서 해 왔고, 그 결과는 아래 문서에 있다.

## 기준 문서 (Google 드라이브 "측창 모터 제어기" 폴더)

작업 전에 먼저 읽고 따른다. 코드와 문서가 다르면 문서가 기준이다.

- 소프트웨어 스펙 v0.9: https://docs.google.com/document/d/1h4CePoZDpxb1MbhL4dKiL9WRhA8tGXZF1WrzBWJW2RQ/edit
- 핀 배정 (ESP32-S3): https://docs.google.com/document/d/1T1Guv7jlq9PdXkdR1XEOk0o6jumPseRxq5PzQkQtSgs/edit
- 설계 정리 (2채널 50W/300W): https://docs.google.com/document/d/1Ofmi7evdES44NVbZpK2k-cxzMU7yUX5PIwzKwpirTas/edit

문서를 읽을 수 없으면 사용자에게 내용을 붙여 달라고 한다. 스펙에 없는 동작을 정해야 하면 혼자 정하지 말고 사용자에게 묻고, 정해진 내용은 문서에 반영하도록 알린다. 문서의 사본을 저장소에 만들지 않는다.

## 개발 환경

- 맥 + VS Code + PlatformIO. 이 폴더(`WinCtrl`)를 열어야 `platformio.ini`가 인식된다. 아두이노 IDE로도 열린다 (README 참고).
- 업로드와 시리얼은 보드의 COM(UART) 포트, 115200bps. USB 라벨 포트(직결 USB)는 쓰지 않는다.
- USB 허브를 거치면 보드가 안 보인 적이 있다. 맥에 바로 꽂는다.

## 구조와 규칙 (스펙 2~4절)

- 네 층: 1 장치(`dev_*`), 2 제어(`ctl_*`), 3 조정(`app_*`), 4 입력(`io_*`). 의존은 위에서 아래로만, 층을 건너뛰지 않는다.
- 핀 번호와 하드웨어 함수는 1층에만 둔다. 핀은 `pins.h`, 상수는 `config.h`.
- 태스크 2개: 제어(코어 1, 10ms 고정)와 화면(코어 0, 약 20ms). 모터, MC, 창 상태는 제어 태스크만, LCD, 소리, 플래시 저장은 화면 태스크만 만진다.
- 시간과 위치는 0.01초 = 1인 정수(`cs_t`). float를 쓰지 않는다. 전류는 mA, 출력은 천분율.
- 창 상태 흐름은 enum 하나와 switch 하나. 상태 바꾸기는 `setState()` 한 곳에서만 한다. State 패턴(상태별 클래스)은 쓰지 않기로 했다.
- 안전 판정(스펙 6절)은 상태와 상관없이 상태 흐름보다 먼저 하고, 어떤 경로로도 건너뛸 수 없게 둔다. 안전 규칙을 약하게 바꾸는 변경은 사용자에게 먼저 확인한다.
- 모델 구분: GPIO39 점퍼가 열림(HIGH)이면 300W, GND면 50W. 점퍼가 빠져도 과부하를 놓치지 않도록 기본을 300W로 정했다. 바꾸지 않는다.

## 확인 방법

```
sh test/run_tests.sh       # 2층, 3층, 화면 글자를 PC에서 시험
sh test/check_compile.sh   # 아두이노 쪽 파일을 가짜 헤더(test/stubs)로 문법 확인
```

코드를 고치면 둘 다 통과시킨다. 아두이노 함수를 새로 쓰면 `test/stubs`에도 넣는다. 실제 확인은 PlatformIO 빌드와 보드 업로드로 한다.

## 책상 시험 메모 (2026-10-16 확인)

- 빌드, 업로드, 50W 점퍼, 엔코더, I2C 화면은 동작을 확인했다.
- 시리얼 로그: 부팅 시 버전, 모델, I2C 선 상태와 장치 주소. 5초마다 `[alive]`와 엔코더 핀 상태. 엔코더 회전과 누름은 `[enc]`.
- 1602 LCD의 I2C 모듈은 전원을 거꾸로 넣어 망가졌다. LCD가 없으면 I2C OLED(SSD1306/SH1106, 0x3C/0x3D)에 같은 두 줄을 그린다 (시험용 대체 화면).
- 24V 회로가 없으면 E-STOP이 걸린다. GPIO1을 3V3에 이으면 풀린다. GPIO6(MC 뒤 전압)은 떠 있으면 MC 에러가 날 수 있어 10kΩ으로 GND에 잇는다.
- 엔코더 방향은 `config.h`의 `ENC_DIRECTION`. 지금 시험 모듈(S1/S2 표기) 기준 -1이고, PEC16을 달면 다시 확인한다.
- 제어 태스크가 읽는 아날로그 핀을 다른 태스크에서 같이 읽지 않는다.

실물로 맞춰야 하는 임시 값은 `README.md`의 "실물로 맞춰야 하는 값"에 있다.
