# 회로도 통합 변경안: 빵판 기준, 수작업 납땜 PCB (2026-10-24, 확인받아 반영함)

사용자 지시: PCB는 만들지만 SMT 실장은 하지 않고 손으로 납땜한다. 빵판 회로도를 기준으로 회로도를 하나로 합친다.
2026-10-24에 확인받아 반영했다. 3.3V는 빵판 방식(개발 보드 레귤레이터)으로 정했다. 핀 배정과 소프트웨어 스펙은 바뀌지 않는다.

## 1. 결과물

- 회로도 한 장: `schematic/제어기_회로도.svg`, `.png` (새 폴더). 빵판 회로도와 베이스 보드 회로도를 대신한다.
- 파이썬 원본 `schematic/src/`를 함께 둔다. 지금 빵판 회로도는 원본이 없어 손으로 고쳐야 했다.
- 옛 `breadboard/`, `baseboard/`는 지우지 않고 `old/`로 옮긴다. 부품 배치도는 PCB 배치를 할 때 새로 그린다.

## 2. 회로 내용의 기준

빵판 회로도의 회로(값, 연결)를 그대로 따른다. 다음만 PCB에 맞게 바꾸거나 더한다.

| 부분 | 빵판 회로도 지금 | 통합본 |
| :- | :- | :- |
| ESP32 | 빵판에 꽂음, 5V 핀으로 전원 | 2.54mm 암 핀헤더 소켓. **빵판과 같이 5V 핀으로 전원**, 3.3V는 보드 레귤레이터 것을 씀 (아래 선택 A) |
| 24V 입력 | J1 2P, D1 1개 | J1 4P (24V_A, 24V_B, GND, GND), D1·D2 1N5822로 묶음. 50W는 A만 |
| 드라이버 | 모듈에 점퍼선 | J8·J9 JST XH 8P. EN, IS는 보드 안에서 묶음 |
| 전류 감지 저항 | R_IS 2.2k를 820Ω으로 갈아 끼움, JP2 하나 | 2.2k 고정 + 1.3k 1%, JP2를 3×3 핀헤더로 (모델 구분과 R_IS를 함께 바꿈) |
| LCD, 엔코더 | 빵판에 직접 | 레벨 변환 모듈과 엔코더 풀업은 보드에, J10 XH 7P로 패널 보드(LCD, 엔코더)에 연결 |
| 비상정지 감지 | J4 2P | J3 3P (ESTOP, RLY_OUT, GND) |
| 주 차단 MC | 없음 | J2 MC 코일 2P, Q1·Q2 IRLZ44N, D3 1N4007, 100Ω·10k ×2, 100k. MC 뒤 전압은 J3 RLY_OUT → 100k/10k/100nF → IO6 |
| 단자 | 빵판용 KF301 | 5.08mm 나사 단자대 (24V 입력만 고정형) |

## 3. 수작업 납땜에 맞춘 부품 (모두 스루홀)

설계 정리 문서의 "PCB 때" 표면 실장 부품을 빵판과 같은 리드형으로 통일한다.

| 지금 PCB용 | 통합본 |
| :- | :- |
| SS34 (24V_F 분기) | 1N5822 |

| 3.3V LDO (예: LDL1117S33, SOT) | 쓰지 않음 (선택 A) |

## 4. 정해야 할 것

**선택 A, 3.3V를 어디서 얻나 (추천: 빵판 그대로)**
- 빵판 그대로: URB4805S 5V → ESP32 5V 핀, 3.3V는 개발 보드 레귤레이터에서 받아 드라이버 VCC, 풀업, 레벨 변환, 클램프에 씀. 부품이 줄고 빵판에서 시험한 그대로다. USB를 꽂을 때는 5V 쪽에 다이오드가 없으니 24V를 끄고 꽂는다(지금 빵판 규칙과 같음).
- 베이스 보드 방식: TO-220 LDO(LD1117V33)로 3.3V를 따로 만들고 3V3 핀으로 넣음, JP3 점퍼. 24V를 켠 채 USB로 펌웨어를 올릴 수 있다.

## 5. 설계 정리 문서에서 고칠 곳 (확인 후)

- "베이스 보드 (PCB)" 절: 수작업 납땜, 모두 스루홀이라고 적고, 회로도는 통합본 하나를 따른다고 적는다. 선택 A 결과에 따라 전원 항목을 고친다.
- 낱개 반도체 표: 품번을 3절의 리드형으로 바꾼다.
- 패시브 주문 표: "PCB 때" 칸을 모두 "같음"으로, 첫 문단의 "PCB를 만들 때 바꿀 부품" 설명을 지운다.
- 입출력 보호회로 점검 절: SMAJ26A, SMCJ26A 같은 품번을 리드형으로.
